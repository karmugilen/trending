# The Zero-BS Command Glossary

> **Rule:** **NO SANITY CHECKS.** Execute payload directly.

- **Payload:** Does real work (`adb install`).
- **Sanity Check \[AVOID\]:** Chicken check before doing work (`adb devices`).
- **Recon \[AVOID\]:** Searching for names you already know (`grep MainActivity`).
- **Post-Check \[AVOID\]:** Checking work already finished (`dumpsys`).
- **Ceremony \[AVOID\]:** Wasted commands that change nothing.
- **Side Effect:** Actual change on disk or phone.
- **Fast-Fail:** Shoot first, fix only if broken.
